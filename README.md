# Noteefy 🎙️📝
**AI-Powered Meeting Assistant & Note Taker**

Turn your voice recordings into structured, actionable meeting notes instantly. Noteefy (formerly Noteefy) combines powerful local transcription with Groq's lightning-fast LLMs to transcribe, summarize, and organize your meetings.

## 🚀 Key Features

*   **🎙️ Smart Recording**: Record audio directly within the app or import existing files.
*   **🧹 Noise Reduction**: Built-in audio cleaning ensures crystal-clear transcription even in noisy environments.
*   **⚡ AI Transcription**: Uses NVIDIA Parakeet for high-accuracy speech-to-text.
*   **🧠 Intelligent Summaries**: Powered by Groq (Llama 3.3 70B), Noteefy generates structured notes with:
    *   Executive Summaries
    *   Key Action Items
    *   Detailed Meeting Minutes
*   **📄 PDF Export**: Export professional, formatted reports with one click.
*   **🔒 Private & Secure**: Runs locally on your machine. API keys are bundled securely (XOR obfuscated) so no setup is required.
*   **🔌 Offline Capable**: Works even if your internet drops (core recording features remain active).

## 📦 Download & Install

**No installation required!** Noteefy is a portable application.

1.  Download the latest release from the [Releases Page](../../releases).
2.  Extract the ZIP file.
3.  Run `Noteefy.exe`.

That's it!

## 🛠️ How it Works

1.  **Launch**: Open the app.
2.  **Record**: Click "Start Recording" or drop an audio file into the "Pending" queue.
3.  **Process**: Click "Process Pending Files".
4.  **Review**: Your AI-generated notes will appear instantly. Click "Export PDF" to save them.
